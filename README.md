# pks4

Общий workspace с двумя ASP.NET Core MVC проектами.

## Проекты

1. [ProductionControl](ProductionControl/README.md)

   Интерактивная система управления производством:
   материалы, продукты, заказы, линии и API.

2. [TouristGuide](TouristGuide/README.md)

   Веб-приложение-справочник по городам и достопримечательностям.

## Как открыть solution

- Solution файл: [pks4.sln](pks4.sln)

## Быстрый запуск проекта

### ProductionControl

```bash
cd ProductionControl
dotnet run
```

### TouristGuide

```bash
cd TouristGuide
dotnet run
```
