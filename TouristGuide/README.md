# TouristGuide

Веб-приложение на ASP.NET Core MVC для просмотра городов и достопримечательностей.

## Возможности

- Список городов и карточки с подробной информацией.
- Страницы достопримечательностей.
- Хранение данных в SQLite через EF Core.
- Автоматическое создание БД при запуске.

## Технологии

- .NET 10
- ASP.NET Core MVC
- Entity Framework Core
- SQLite

## Запуск

1. Перейдите в папку проекта:

   ```bash
   cd TouristGuide
   ```

2. Соберите проект:

   ```bash
   dotnet build
   ```

3. Запустите приложение:

   ```bash
   dotnet run
   ```

4. Откройте URL из консоли (обычно http://localhost:5xxx).

## База данных

- Файл БД: `tourist-guide.db`.
- База создаётся автоматически при старте.

## Структура проекта

- `Controllers/` — контроллеры приложения.
- `Data/` — контекст базы данных.
- `Models/` — модели домена.
- `Views/` — Razor-представления.
- `wwwroot/` — статические файлы.
